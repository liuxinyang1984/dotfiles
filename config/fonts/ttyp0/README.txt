UW ttyp0（OTB）— 与 SunSong 配对的半角英文

来源: https://people.mpi-inf.mpg.de/~uwe/misc/uw-ttyp0/
族名: Ttyp0 OTB
收录: 14/16/18/22 Regular+Bold（7×14 / 8×16 / 9×18 / 11×22）

安装到: ~/.local/share/fonts/ttyp0/
  cp -a files/*.otb ~/.local/share/fonts/ttyp0/ && fc-cache -f ~/.local/share/fonts/ttyp0

monospace 选档见 config/fonts/sunsong/conf/10-sunsong-render.conf
（物理 26 无对应 ttyp0，仍用 SunSong Roman）
